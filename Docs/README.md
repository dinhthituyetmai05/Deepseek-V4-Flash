# 03-Docs — Tài liệu thiết kế / Design documents

| Thư mục | Nội dung |
|---|---|
| `spec/` | Đặc tả từng khối: `<khối>_spec.md` theo `_TEMPLATE_block-spec.md` |
| `architecture/` | Kiến trúc tổng thể, microarchitecture, memory map |
| `algorithm/` | Mô tả thuật toán, phân tích fixed-point |
| `waveform/` | Waveform / timing diagram nguồn (WaveDrom `.json`) + `.svg` |
| `diagrams/` | Sơ đồ khối nguồn (`.drawio`) + `.svg/.png` |

Hình luôn lưu kèm file nguồn sửa được.
